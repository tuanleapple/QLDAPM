# Synthetic API report fixtures

Keep these files in Git with the local seed tooling:

- `api-demo-report.pdf`: a one-page PDF with synthetic text.
- `api-demo-report.docx`: a small OpenXML document with the same synthetic text.

The files contain no personal data or credentials. The seed reads both valid files before
opening its database connection, and the report service unit test validates them through
the upload validator. Private copies generated by seed belong in the ignored report storage
directory; these source fixtures must stay in `backend/tools/fixtures/`.
